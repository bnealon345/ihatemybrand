## How we work with Claude
- One shared Claude login for now. Each founder's Claude Code sessions auto-connect to Remote Control, so both can open any live session at https://claude.ai/code and type into it.
- Only one person can host a live session in VS Code; the other follows in the browser. Alternate who hosts.
- Durable knowledge goes in this repo, not in Claude's per-machine memory. If Claude learns something both founders should keep, add it here.
